# NASA 1 km 细节瓦片数据模块

适用于世界地图分区档案 1.3.0 或更高版本；它只是可选地图数据，不含程序。

1. 完全退出世界地图分区档案。
2. 将压缩包内的 `assets\nasa-1km` 文件夹复制到程序目录的 `assets` 文件夹，保持原有目录结构和文件名。
3. 启动程序，勾选“NASA 2 km 底图”；滚轮放大到 800% 以上即可自动显示附近的 1 km 细节瓦片。

本模块由 NASA Blue Marble January 2004 官方 500 m 分块源降采样为 1 km/像元、648 张 10°瓦片。每张包含配准世界文件和 WGS 84 投影文件；`SHA256SUMS.txt` 可用于逐文件完整性检查。NASA 月图是历史合成影像，不是实时卫星数据。

移除整个 `assets\nasa-1km` 文件夹即可卸载；2 km 全球 NASA 底图和其他功能不受影响。
