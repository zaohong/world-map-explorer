# 世界地图分区档案 1.8.0 应用补丁

适用于 1.7.0。此补丁只更新主程序，为地图点击/经纬度搜索的精确点增加青色靶心，与红黄配准点区分；地图、9,800 格档案、土地覆盖以及 NASA 细节数据均不变。

## 更新方法

1. 退出“世界地图分区档案”。
2. 将现有 `WorldMapExplorer.exe` 备份为 `WorldMapExplorer-v1.7.0.exe.bak`。
3. 将补丁中的 `WorldMapExplorer.exe` 复制到原安装目录。
4. 启动后，地图点击或经纬度搜索的精确点会以靶心显示；平移/缩放时靶心同步移动。地名/编号搜索仍只高亮分区，不显示未经数据支持的精确点。

若要回退，退出程序后用备份的 1.7.0 EXE 替换当前 EXE。此补丁不含地图/数据，不联网，也没有自动更新器或数字签名。
