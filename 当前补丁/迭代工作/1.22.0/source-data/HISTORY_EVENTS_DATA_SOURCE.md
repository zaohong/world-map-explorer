# 历史事件数据模块

运行数据文件：`data/world-events.tsv`（UTF-8，无需联网）

每条记录包含公元纪年、事件类别、地点、中文标题、简要说明和来源链接。年份按时间先后排列；公元前年份用负数表示，公元前1年之后直接为公元1年，不设公元0年。古代事件若年代存在争议，会在标题或说明中标注“约”“传统纪年”等提示。

每条记录提供对应的 Wikipedia 条目链接作为进一步查阅入口。中文短说明为本项目面向地图播放界面编写的摘要，不是原文摘录，也不代表穷尽所有历史解释。事件在播放时按相邻时间节点覆盖的年份筛选；该时间段没有条目时，面板显示时间上相近的记录并明确标注为附近事件。

数据文件独立于疆域栅格和地理档案。更换或移除事件文件不会改变地图、历史疆域、网格和既有资料。格式与质量检查位于 `qa/world_event_checks.js`；程序及检查脚本将事件数量限制为最多 10,000 条。
