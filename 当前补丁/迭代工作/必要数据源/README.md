# 必要原始数据

此文件夹保留对地图和离线数据重建有实际用途的原始来源文件，不含运行程序。超过普通 Git 单文件限制的两份原始数据作为 GitHub Release 附件提供，路径和 SHA-256 见仓库根目录 `SUPPLEMENTAL-DATA.md`。

- Natural-Earth-High-Resolution：Natural Earth 21,600 × 10,800 全球地形底图原始包及配套定位、来源资料。
- WorldPop-2023：2023 年全球人口原始 GeoTIFF、汇总器源码和数据来源说明。
- 日常运行不需要这两份原始数据；运行所需地图素材和已处理专题数据在 v1.23.0 Release 的完整运行包内。
